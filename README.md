# Yining Wu — Personal Website

A responsive academic portfolio for Yining Wu, built with plain HTML, CSS, and JavaScript for simple GitHub Pages deployment.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder.

The website has no package dependencies or build step.
